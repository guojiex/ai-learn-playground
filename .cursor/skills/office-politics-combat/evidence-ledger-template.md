# Evidence Ledger Template：证据台账

用于长期防御 PUA、甩锅、私下施压、流程卡口。证据台账不是情绪日记，只记录可引用事实。

---

## 1. 记录原则

- 写事实，不写动机判断。
- 记录原话，不转述成攻击性评价。
- 每条记录带时间、渠道、链接或截图位置。
- 只记录工作相关内容，不挖私生活，不造证据。
- 当天记录，当天备份；时间久了细节会变形。

---

## 2. 单条记录模板

```text
日期：

当前状态：open / waiting / resolved / blocked

证据位置：

```

---

## 3. 证据分级

| 等级 | 证据 | 可用性 |
|------|------|--------|
| L1 | 私聊截图 / 个人记录 | 可自保，公开时慎用 |
| L2 | 群聊消息 | 可用于团队内对齐 |
| L3 | Jira / 文档评论 | 可用于项目复盘 |
| L4 | 邮件 / 会议纪要 | 可用于正式升级 |
| L5 | 多方确认的决议记录 | 可用于责任归属 |

优先把 L1 推到 L3，而不是永远囤私聊截图。

---

## 4. 常见事件分类

### 模糊 PUA

```text
标签：PUA / 模糊评价
触发句：情绪大 / 不主动 / 格局不够 / 不够 owner / 不够合作
应对：要求具体 case、期望动作、衡量标准
```

### 甩锅

```text
标签：责任转移
触发句：这个你们自己处理 / 你自己协调 / 不是我们的问题
应对：确认事实、引用分工、要求正确 owner
```

### 降级处理

```text
标签：风险降级
触发句：只是小 bug / 内部看一下 / 不用这么正式
应对：要求风险等级、判断依据、风险接受人
```

### 私下施压

```text
标签：不留痕施压
触发句：别写文档 / 先别同步 / 私下对一下就行
应对：给台阶，但把结论写成中性纪要
```

## 5. 周度整理模板

每周整理一次，不超过 10 分钟：

```text
本周新增风险：
本周新增阻塞：
本周已闭环事项：
仍缺 owner 的事项：
仍缺 deadline 的事项：
下周需要公开化 / 升级的事项：
```

这份整理可直接转成周报、1on1 纪要或升级材料。
