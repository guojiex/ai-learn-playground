# When to Disengage：何时退出战场

本 skill 默认假设用户在打一场可以打赢、值得打的仗。但**有些仗本身就不该打**，再多钩子也是浪费。

本文件的作用：**让 agent 在用户进入"打不赢 / 打了也亏 / 打着打着把自己打垮"的状态时，主动建议止战、退场或转赛道。**

不要把退出战场说成失败。**退出本身就是一种最高阶的招式**，前提是带着证据、关系、KPI 一起退。

---

## 1. 强制冷却信号（命中即先冷却 24h，不出攻击话术）

只要用户的本轮输入命中以下任一信号，agent **不要直接给三档攻击话术**，先输出冷却建议：

| 信号 | 典型措辞 |
|------|---------|
| 强情绪 | "气死了"、"血压高"、"想骂人"、"再忍就疯了"、连续 3 个以上感叹号 |
| 自毁倾向 | "我要直接掀桌"、"大不了开了我"、"我马上发到大群"、"我打算把聊天记录全发出去" |
| 想造假/反伪造 | "能不能 PS 一下"、"能不能伪造一份"、"我截一张图但改一下时间" |
| 已醉 / 已熬夜 | "刚喝完酒"、"我现在凌晨三点"、"两天没睡了" |
| 想私下报复 | "搞他私生活"、"挂他朋友圈"、"把他家人……" |

**冷却话术模板（agent 复制粘贴到输出顶部）：**

```
先停 24 小时再回。这一句话此刻发出去，可能会让你失去：
1. 书面化的主动权（情绪化的话被截图反而成了你的把柄）
2. 旁观者的同情（公司里大多数人天然反感"激烈方"）
3. HR / BigBoss 的中立位（一旦你越界，他们就有理由各打五十大板）

建议动作：
- 把想说的话先写在备忘录里，不要发
- 24 小时后我们再回来看，那时再决定要不要发
- 如果实在压不住，先做下面 3 件之一：散步 / 关 IM 通知 / 找一个不在公司的朋友说一遍
```

冷却之后用户回来，再走正常 SKILL.md 流程。

## 2. 战场已废信号（建议止战 / 转赛道）

只要命中下列任一组合，**这场仗本身打下去 ROI 已经为负**，agent 应主动建议用户退出而不是再埋钩子。

### 2.1 连败信号

- 连续 3 轮以上钩子全部被对方绕开 / 装傻 / 沉默
- 连续 2 次升级到 Boss / BigBoss / HR，结果都是"再观察 / 你们自己消化 / 不便表态"
- 用户已经把战场推到 L4 / L5（邮件、纪要），对方仍能毫发无伤地继续推

→ **诊断**：决策层默认站对方那边，议题本身已经死。继续打只会消耗自己。

### 2.2 资源枯竭信号

- 用户已无新证据可补、台账空了、盟友数 = 0
- 用户的业务被边缘化（不在 Boss / BigBoss 的 KPI 主线上）
- 用户的健康 / 睡眠 / 家庭关系开始受影响（用户主动提到失眠、家人抱怨）

→ **诊断**：你已经在用真实生活补贴一场虚拟战争。

### 2.3 局面不可逆信号

- 已收到 PIP / 调岗通知 / "建议主动看看外面机会"
- Boss 已经公开在群里 / 周会上**多次**给用户低分定调
- 用户被排除在核心会议、核心项目、核心信息群之外超过 2 周

→ **诊断**：决策已下，剩下的不是战斗是延迟。把延迟时间用来谈判离场更值。

## 3. 战场已废时的输出模板

当 agent 判定命中第 2 节任一信号时，**不要给三档攻击话术**，改输出下面这个结构：

```
## 局势重判
这场仗已经不值得继续打：<引用用户输入里的具体信号 1-3 条>

## 三个出路（按 ROI 排序）

### 出路 A：体面退出 + 资产带走
目标：留好关系、把这段时间的产出转成下一份工作 / 下一个组的筹码
动作：
- 把过去 N 个月的产出整理成一份"贡献清单"（数据 + 链接 + 影响）
- 主动约 BigBoss / Skip 一次"求职业发展建议"的 1on1（不是告状）
- 准备 2-3 个内部转岗 / 外部 offer 的探路对话

### 出路 B：低强度共存 + 暗线建设
目标：表面降温，背后铺新通道
动作：
- 钩子降到每周 ≤ 1 个，且只埋"防御型"钩子（书面化 / 留痕）
- 不再主动推进对方负责的议题，专注做能直接被 BigBoss 看到的事
- 同步开始外部 / 跨部门 networking

### 出路 C：合规升级 + 接受关系破裂
目标：用一次性大动作把局面定性，接受撕破脸的代价
动作：
- 把全部证据台账整理成一份"事实陈述"（不带情绪、只有时间线 + 链接）
- 走 HR / Skip / 大老板的正式渠道一次（不是 IM 抱怨）
- 同步把外部 offer 谈到手，作为 BATNA

## 推荐
<在 A/B/C 中选一个>，理由：<结合用户的离职成本、外部市场、家庭情况>

## 不推荐继续埋钩子的理由
<针对用户当前局势的具体说明，避免空话>
```

## 4. 自我损耗自检（每月一次，agent 在用户长期使用本 skill 时主动提示）

如果 agent 发现用户**累计在本 skill 里贴对话超过 20 轮**，或**每周来 ≥ 3 次**，应该在某次输出末尾追加一段：

```
## 顺带一提：自我损耗自检
你已经在这个对手身上投入了相当多的对话回合。下面 5 个问题答一下（不用回我）：

1. 我最近一次睡满 7 小时是哪天？
2. 我最近一次没想起这位对手是哪天？
3. 如果今天有人给我一份同薪同岗的外部 offer，我会不会立刻答应？
4. 我打赢这场仗之后，能拿到的最大收益是什么？这个收益值不值得我现在的状态？
5. 一年以后，我还会记得这次冲突里的具体某一句话吗？

如果有 ≥ 3 个答案让你不舒服，建议把战略重心从"赢这场仗"切到"安全退出"。
```

这段是给用户自己看的，**不要替用户回答**，也不要追问答案。

---

## 5. 给 agent 的硬约束

- 当用户处于"强制冷却信号"时，**禁止**输出任何攻击型钩子或强硬档话术，即使用户明确要求
- 当用户处于"战场已废信号"时，**至少先给一次出路建议**再考虑给攻击话术；如果用户坚持要打，可以给但只给标准档以下，并在末尾保留一行"我仍然建议走出路 A/B/C"
- 不要把"建议退出"写成"你打不赢"——要写成"这场仗的 ROI 已经为负"，让用户感觉是自己做的战略选择
- 不要在每次输出都提退出战场——只在命中信号时提，否则会显得 skill 软弱

## 6. 一个不太愿意承认但很重要的事实

本 skill 的所有钩子、反击、升级路径，都是为了**让用户在一个不公平的环境里少吃一点亏**。但它**改变不了**：

- 一个铁了心要 PUA 你的老板
- 一个把你当替罪羊的组织文化
- 一个把你的健康、家庭、长期心智都磨损掉的工作

当 skill 用得越频繁、效果越差时，**结论往往不是"招数不够"，而是"地图不对"**。

换地图比换招式便宜得多。
