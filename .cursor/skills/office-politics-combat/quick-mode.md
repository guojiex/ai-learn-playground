# Quick Mode：快速回复模式

用户在工位上被 @ 了一句、急着回复，没空读完整 framework 输出时使用。

本模式存在的意义只有一个：**让用户在 60 秒内拿到一句可以直接抄走的话，并且不丢掉钩子。**

---

## 1. 触发条件（满足任一即进入 Quick Mode）

- 用户输入 < 50 字 + 出现"快 / 急 / 在线等 / 一句话 / 怎么回 / 帮我回一下"
- 用户明确说"不要分析了 / 直接给话术 / 简短点"
- 用户连续两轮抱怨上一次输出"太长 / 看不过来"
- 用户贴的对话本身就是一句话（没有上下文、没有诉求说明）

**反触发条件（即使命中上述也不要进 Quick Mode）：**

- 涉及风险接受人 / 安全 / 发布 / 审计 / 合规 → 必须走完整模式（这种场合"快"反而是坑）
- 用户明确说要写邮件 / 周报 / 升级材料 / 1on1 纪要 → 必须走完整模式
- 用户已经情绪化（连续感叹号、"气死了 / 我要辞职 / 想骂人"）→ 切到 [when-to-disengage.md](when-to-disengage.md)，不给攻击话术

---

## 2. Quick Mode 输出模板

**严格按这个结构，不要扩写**：

```
## 局势一句话
<10 字内：对方在做什么动作>

## 三档话术
- 温和：<≤ 30 字>
- 标准：<≤ 30 字>（默认埋 1 个钩子）
- 强硬：<≤ 30 字>

## 钩子
<本轮埋的那 1 个钩子是什么类型 / 触发信号是什么>，详见 [hook-patterns.md](hook-patterns.md) 对应编号的章节

## 推荐
<档位> —— 一句话理由

## 如果想看完整分析
回复"展开"或"完整版"，我按 SKILL.md 固定模板再出一版。
```

---

## 3. Quick Mode 内部速判清单（agent 自己心里过，不输出）

1. 对方这句是哪个动作？（甩锅 / 模糊 / 试探 / 加码 / 装傻）
2. 我方筹码够不够走标准档以上？不够就把"标准"做成实际的温和、强硬做成实际的标准
3. 这一轮最值得埋的那一个钩子是什么？（不要贪多，Quick Mode 只埋 1 个）
4. 推荐档默认走标准档，除非命中下面的降档条件：
   - 对方是 BigBoss 本人 / HR / 跨级一把手 → 降到温和
   - 用户处于试用期 / PIP / 离职窗口 → 降到温和
   - 对方刚在群里公开下场 → 升到强硬（跑不掉了，干脆把书面化做足）

---

## 4. 三档话术的字数与语气尺度

| 档位 | 字数 | 语气 | 钩子 |
|------|------|------|------|
| 温和 | ≤ 30 字 | 退一步、留余地、不接锅 | 不埋（Quick Mode 温和档不背钩子） |
| 标准 | ≤ 30 字 | 平视、就事论事、要求具体化 | 必须埋 1 个 |
| 强硬 | ≤ 30 字 | 冷硬、明确升级路径、不留情绪 | 钩子嵌在升级动作里 |

**Quick Mode 反例（不要这样写）：**

- ❌ "我理解你的考虑，但是从业务全局来看……"（废话，超字数）
- ❌ "建议把这个问题升级到 Boss 那边一起讨论一下，因为……"（拖沓，理由不该写在话术里）
- ❌ 30 字里塞 2 个钩子（用户念不出来）

**Quick Mode 正例：**

- 温和：`先按现状走，有新口径同步我。`
- 标准：`方便给个具体 owner + 排期吗？我按这个对产品。`（钩子：责任归位 + 时间戳）
- 强硬：`这个口径建议在群里 @ Boss 拍一下，我后面好推。`（钩子：公开化）

---

## 5. 从 Quick Mode 升级到完整模式

用户说"展开 / 完整版 / 详细分析 / 帮我准备升级材料"时，agent **不要重新问一遍问题**，直接把刚才 Quick Mode 用过的那段对话送进 SKILL.md 的固定输出模板，复用同一组钩子。

这样用户能感觉到"AI 记住了我们刚才那一仗"，而不是从零开始。

---

## 6. 给 agent 的硬约束

- Quick Mode 输出**总长度不得超过 200 字**（含模板里的标题）
- 不输出权力三角、叙事框架、风险打分这些分析过程
- 不要追问超过 1 个问题；缺信息就直接按"标准档默认假设"出，并在末尾用一行括号标出假设
- 不要在 Quick Mode 里写"建议你再观察一下"这种废话——用户已经在火线上了
