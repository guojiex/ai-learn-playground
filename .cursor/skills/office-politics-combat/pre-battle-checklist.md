# Pre-Battle Checklist：事前防御清单

用于用户想“提前准备”、尚未进入具体冲突，或担心未来被 PUA / 甩锅 / 私下施压时。目标不是主动挑事，而是让任何攻击落到事实、边界、owner、deadline 和风险接受人上。

---

## 1. 先判断当前要防什么

| 信号 | 可能风险 | 预备动作 |
|------|----------|----------|
| 老板常私下给模糊评价 | PUA / 秋后算账 | 建 1on1 纪要习惯，要求具体 case 和标准 |
| QA / 平台方常说“内部看一下” | 降级处理 / 不留痕 | 把问题锚到 Jira / 文档，并要求 owner / deadline |
| 对方喜欢口头承诺 | 事后不认 | 会后同步“我理解对齐了几点” |
| 任务经常临时加急 | 优先级锅 | 条件接受，要求拍优先级 |
| 流程被拿来卡你 | 权力不对等 | 反问流程 owner、SLA、升级路径 |

---

## 2. 每周准备四类材料

### 事实材料

- 本周完成了什么，链接是什么
- 哪些事项被谁阻塞，阻塞时间多久
- 哪些风险已同步，当前状态是什么
- 哪些承诺有 owner / deadline，哪些没有

### 边界材料

- 哪些事属于我方 owner
- 哪些事需要 QA / 平台 / 产品 owner
- 我方可以提供什么辅助动作
- 我方不能替对方承担什么决策

### 话术材料

提前准备 3 句默认回复：

> 具体是指哪件事？我看一下对应上下文。

> 为避免理解偏差，我整理到文档 / Jira 里，大家按同一个结论推进。

> 如果暂不处理，麻烦明确风险接受人和接受周期，我这边按结论记录。

### 盟友材料

- 谁也遇到过同类问题
- 谁在群里愿意基于事实补充一句
- 哪个上级只适合看业务风险，不适合听人际矛盾
- 哪个渠道适合公开，哪个渠道只适合试探

---

## 3. 进入冲突前的 30 秒自检

回复前先问自己：

- 我是在回应事实，还是在回应情绪？
- 这句话被截图给 BigBoss / HR 看，会不会失分？
- 我有没有不小心接下 owner / deadline / 验收标准？
- 我能不能把它换成“需要谁确认什么”？
- 这轮我要拿到的一个最小成果是什么？

最小成果只能选一个：owner、deadline、风险等级、书面结论、升级入口。

---

## 4. 默认防御原则

1. 不自证人格，只要求具体 case。
2. 不接无 owner / 无 deadline / 无验收标准的活。
3. 不在私聊里做正式承诺。
4. 口头会后补纪要，群聊争议沉淀到 Jira / 文档。
5. 对方越模糊，我方越具体；对方越私下，我方越留痕。
