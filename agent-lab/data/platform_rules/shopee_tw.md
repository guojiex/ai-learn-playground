# 蝦皮 Shopee 台灣 標題與文案規則

## 標題規則
- 標題字數上限：120 字元（含空格）。
- 建議結構：品牌 + 商品名 + 規格 + 適用對象 + 促銷詞。
- 不可使用全大寫英文（如 "BEST SELLER"），系統會降權。
- 前 40 字元最重要，會顯示在搜尋結果列表，建議放品牌與核心賣點。

## 違禁詞
- 不得使用「最便宜」「最低價」「全網第一」等絕對性用語（違反公平交易法）。
- 不得出現「保證治癒」「根治」「特效藥」等醫療療效詞。
- 不可堆砌無關關鍵字（如賣毛巾卻寫「iPhone」），系統會判定為垃圾 listing。

## Hashtag 規範
- 每個商品最多 5 個 hashtag，格式為 #中文 或 #English。
- hashtag 需與商品直接相關，不可用熱門但無關的標籤引流。
- 建議搭配季節性標籤：#夏日必備 #年終慶 #雙11。

## 價格與促銷
- 現貨商品可標註「現貨免運」「24h 出貨」。
- 預購商品必須在標題或描述首行標明「預購 X-Y 天」。
- 限時折扣建議用 🔥 或 ⚡ 符號引導，但不可過多（≤2 個 emoji/標題）。
