# PChome 24h 標題與文案規則

## 標題規則
- 標題字數上限：50 字元（含空格），比蝦皮短很多，要精簡。
- 結構：品牌 + 商品名 + 核心規格，促銷詞放描述區。
- 不可使用 emoji，PChome 搜尋對特殊符號支援差。

## 違禁詞
- 不得使用「破盤價」「跳樓價」等浮誇詞。
- 醫療器材需標明許可證字號。
- 不可在標題放競品品牌名。

## 出貨規範
- 24h 到貨商品需確認庫存充足，否則會被降評。
- 偏遠地區（花東/離島）不保證 24h，需在描述中註明。
- 大件商品（>20kg）走宅配，不走 24h 物流。

## 描述區規範
- 首段放商品核心賣點（3-5 行）。
- 規格表用表格呈現，消費者掃視效率最高。
- 底部放退換貨政策與客服聯絡方式。
