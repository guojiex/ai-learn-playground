# Momo 購物網 標題與文案規則

## 標題規則
- 標題字數上限：60 字元（含空格）。
- 結構：品牌 + 系列 + 商品名 + 規格，建議按此順序排列。
- Momo 搜尋權重偏品牌名，品牌一定要放最前面。

## 違禁詞
- 不得使用「致癌」「有毒」等負面詞描述競品。
- 保健食品不可宣稱「治療」「預防」疾病。
- 不可使用「政府認證」除非附上證書編號。

## 圖片規範
- 主圖需白底，商品佔圖片面積 ≥ 60%。
- 不可在主圖加水印或促銷文字（促銷資訊放圖片描述）。
- 最多 9 張圖，建議前 3 張為：主圖 / 細節 / 使用情境。

## 促銷與定價
- Momo 常態活動：美妝節 / 3C 大促 / 周年慶，建議提前備貨。
- 「下殺」「折扣」需標明原價與折扣後價格。
- 滿額贈需在描述首行醒目標註門檻與贈品。
