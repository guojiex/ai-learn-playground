# 06 · Web UI 设计

UI 是 agent-lab 的**演示主界面**。CLI 仍然保留为脚本与测试主接口，二者**共用 `internal/*` 业务层**。

## 目标

- 让多轮对话、工具调用、planner DAG、multi-agent 消息流、HITL approval、trace 时间线在一屏内看见。
- 零外部前端构建：Go `html/template` + 原生 fetch + SSE/ReadableStream + 少量手写 CSS。
- 单二进制：所有模板与静态资源 `embed.FS` 打包进 `cmd/web`。

## 技术栈

| 层 | 选型 | 不选什么 |
|----|------|--------|
| Server | Go `net/http` (标准库 mux 即可) | gin / echo / fiber |
| 模板 | `html/template` | jinja / handlebars |
| 资源打包 | `embed` | esbuild / vite / webpack |
| 客户端交互 | 原生 fetch + `EventSource` (SSE) | React / Vue / Svelte |
| 样式 | 单文件手写 CSS (CSS 变量 + flex/grid) | Tailwind / Bootstrap |
| 图标 | 行内 SVG | 图标字体 |

不引 Node 工具链。需要 syntax highlight 时用 `<pre><code>` + 极简正则上色，足够展示 JSON。

## 端口与协议约定

| 角色 | 默认地址 | 备注 |
|------|---------|------|
| Web UI (`cmd/web`) | `http://127.0.0.1:8090` | 浏览器入口 |
| Chat backend (llama.cpp / Ollama) | `http://127.0.0.1:8080/v1` | 对应 `OPENAI_BASE_URL` |
| Embedding backend (M5+) | `http://127.0.0.1:8081/v1` | 对应 `AGENTLAB_EMBED_BASE_URL` |

## 信息架构

左侧固定导航 + 右侧主面板。每个面板由一个里程碑负责落地，没填的显示"M? 启用后开放"占位。

```
agent-lab
├── Chat            (M0/M1)        多轮对话 / 流式
├── Tools           (M2/M3)        工具与最近调用
├── Plan            (M6)           Plan DAG 与执行进度
├── Multi-Agent     (M7)           4 角色消息流
├── Approvals       (M8)           HITL 待办 / 审批
├── Traces          (M9)           trace 列表 / 时间线
├── Router          (M10)          模型路由命中
└── Settings                       Profile / BaseURL / Model 显示
```

## 与 CLI 的关系

- `cmd/chat` 不变，作为脚本与冒烟测试入口。
- `cmd/web` 在内部直接复用 `internal/llm` / `internal/agent` / `internal/memory` / ...
- 所有持久化在 `data/agent.db` (M4 起)，CLI 与 Web 共享同一份状态。

## 多轮对话的 UI 行为 (v1)

- 单页布局：左侧会话列表 (M0 阶段为内存) + 右侧消息区 + 底部输入。
- 用户提交 → 浏览器 fetch `POST /api/chat` → Server 走 `LLMClient.ChatStream` → 每个 token 通过 SSE 推回。
- "停止"按钮：客户端关闭 `EventSource` → Server ctx 取消 → backend 中断生成。
- 角色卡 (system prompt) 顶部可折叠，编辑后下次生效，不污染既有消息。

## 后续里程碑的 UI 增量

- **M1**：会话列表持久化、`:reset/:save/:load` 等价按钮、"摘要触发"提示条。
- **M2/M3**：消息流中插入 tool call / observation 折叠卡片；右侧 Tools 面板列出工具 schema。
- **M6**：DAG 可视化 + 任务状态 (pending/running/ok/fail/replan)。
- **M7**：4 列消息流，顶部 round 编号；终止/反馈合并实时高亮。
- **M8**：待办列表 + 详情面板 + 参数 diff，一键 approve/reject/edit；high-risk 节点全局徽标。
- **M9**：Trace 列表 (按 goal/status/duration 过滤) + 火焰图时间线 + span 详情 JSON。
- **M10**：命中统计柱图 + 最近 N 次 fallback chain；A/B 比例切换。

## 验收标准 (UI 框架本身, 在 M0 落地)

- [ ] `go run ./agent-lab/cmd/web` 起服后访问 `http://127.0.0.1:8090/` 可见 Chat 页面。
- [ ] Chat 页面能完成一次完整流式问答 (走 fake-openai 即可)，token 实时刷出。
- [ ] "停止"按钮在生成中可中断，server 端 ctx 真的被取消 (后端日志可见)。
- [ ] 静态资源走 `embed.FS`，二进制单文件可分发。
- [ ] 左侧导航有占位 (Plan/Multi/Approvals/Traces/Router/Settings)，点击进入"M? 启用后开放"占位页。
- [ ] `go vet` / `go test` 通过；新增 handler 至少 1 条单测覆盖 `POST /api/chat` 的 SSE 中转。

## 安全与边界

- 默认仅 listen `127.0.0.1`，不暴露公网。
- 不做登录/鉴权 (本地学习项目)。如未来要走 LAN 演示，加 basic auth 走 ADR。
- 用户输入仅在本地处理，不外传；所有 LLM 调用均通过 `OPENAI_BASE_URL`，遵循 ADR-0002 (本地优先)。
